# HOST-5S-001 — Compatibility Profile

**Status:** SUPERSEDED / COMPATIBILITY PROFILE  
**Canonical SSOT:** `KCOS-5S-001 — Engineering & Operations 5S Standard`

This document is retained only as a compatibility entry for existing project references. It MUST NOT be treated as a competing or narrower 5S standard.

## Rule

All host/node 5S requirements are governed by `docs/KCOS-5S-001.md`.

The host/node layer is an execution profile of the global KCOS 5S standard and applies regardless of whether KCOS operates on one machine or multiple machines.

Existing references to `HOST-5S-001` SHALL resolve to `KCOS-5S-001`.

## Migration

- Do not create new requirements under HOST-5S-001.
- New host/node controls MUST be added to KCOS-5S-001 or a subordinate standard explicitly governed by it.
- Existing project references may remain temporarily until migrated.

## Core Rule

**5S is an environment-wide engineering discipline, not a single-host-only rule.**
